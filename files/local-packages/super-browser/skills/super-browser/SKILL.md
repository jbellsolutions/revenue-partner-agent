# Super Browser — Revenue Partner local runtime

This release includes a **local, unlaunched** Super Browser runtime inside the Orgo template. It does not provide a hosted bridge or live public endpoint.

Use the configured `super-browser` MCP server or baked `/usr/local/bin/super-browser` command after the image is built. Only exact allowlisted local Playwright fixtures and bounded direct public-IP-literal raw HTTP have conditional executable readiness. Public Playwright navigation and hosted providers are non-executable. Approval-required production work remains `awaiting_approval` and cannot execute inside this template runtime.

Always run the five-round council, report provider readiness, and verify evidence. Do not claim an Orgo deployment, provider session, or hosted service unless it has been launched and read back.
