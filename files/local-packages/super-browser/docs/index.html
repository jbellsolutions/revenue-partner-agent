Super Browser — Revenue Partner local runtime

This release contains a baked, local, unlaunched browser/research runtime. It provides no hosted bridge, public endpoint, scheduled service, or local production-approval mechanism.

Verify

super-browser doctor
super-browser providers
super-browser live-test --provider fixtures

Fixture results prove exact allowlisted local Playwright fixture execution and bounded public-IP-literal raw HTTP handling only. Public Playwright navigation and hosted providers are non-executable.

Safety

Only policy-classified read work may dispatch. Mutating, credential-bearing, external-write, and destructive work remains awaiting approval and cannot execute in this image.

Use the configured local MCP server or baked command after the Orgo image is built. Do not clone another runtime, run floating installers, or mutate the running image.
